Fashion Product Data Visualization Dashboard
Project Overview

The Fashion Product Data Visualization Dashboard is an interactive Power BI project developed to analyze fashion product data. The dashboard provides insights into product brands, categories, pricing, markdown percentages, customer ratings, returns, seasons, and stock availability. It transforms raw data into meaningful visualizations using interactive charts, cards, slicers, and navigation buttons.

Project Objectives

The main objective of this project is to analyze fashion products across different brands and categories. It helps users understand product pricing, markdown patterns, customer satisfaction, return information, and stock availability. The project also aims to develop practical skills in data cleaning, data transformation, DAX calculations, and interactive dashboard design using Power BI.

Tools and Technologies

This project was developed using Microsoft Power BI, Power Query, DAX, and Microsoft Excel. Power BI was used to create interactive visualizations, Power Query was used for data cleaning and transformation, and DAX was used to create calculated measures and analyze the dataset.

Dataset Description

The dataset contains information about fashion products, including brand, category, color, size, current price, original price, markdown percentage, customer rating, return status, return reason, season, purchase date, and stock quantity. These fields help analyze product distribution, pricing, customer satisfaction, and inventory-related information.

Data Cleaning and Transformation

Data cleaning was performed using Power Query to prepare the dataset for analysis. The data types of different columns were checked and standardized. The return-status column was converted into readable values such as Yes and No. Price-related fields, markdown percentages, and missing values were reviewed to improve data quality and ensure that the dataset was suitable for visualization.

Dashboard Features

The dashboard includes interactive visualizations that help users explore fashion product information. It presents product counts by brand and category, average current prices, stock quantities, customer ratings, and returned product information. Slicers and navigation buttons allow users to filter the data and move between dashboard pages.

Brand and Category Analysis

The brand and category analysis page provides an overview of product distribution across different fashion brands and categories. Users can compare the number of products available in categories such as Tops, Bottoms, Dresses, Shoes, Accessories, and Outerwear. Interactive filters make it easier to examine specific brands and product categories.

Pricing and Markdown Analysis

The pricing and markdown analysis page focuses on the original price, current price, and markdown percentage of fashion products. It helps users compare pricing patterns across brands and categories. The dashboard provides a visual representation of product prices and discount-related information.

Return and Customer Satisfaction Analysis

The return and customer satisfaction page analyzes returned products, return reasons, and customer ratings. It helps users explore patterns in product returns and understand how customer ratings are distributed across different categories and brands.

Seasonal Product Analysis

The seasonal analysis page explores the distribution of fashion products across different seasons. It helps users compare product availability by season, brand, and category through interactive charts and filters.

Key Metrics

The dashboard uses important metrics such as total product count, total stock quantity, average current price, average customer rating, and returned product count. These metrics provide a quick summary of the available fashion product data and support further analysis through interactive visualizations.

Dashboard Design

The dashboard uses a professional brown-and-cream-inspired design to create a premium fashion-related appearance. It includes cards, charts, slicers, navigation buttons, hover effects, and shadow effects. The layout is designed to present information clearly while providing a visually attractive and interactive user experience.

Skills Demonstrated

This project demonstrates my skills in Power BI dashboard development, data cleaning, Power Query, DAX calculations, data visualization, interactive report design, data analysis, and business-oriented data storytelling.

Future Improvements

In the future, the dashboard can be enhanced by integrating actual sales revenue and transaction-level data. Additional features such as sales performance analysis, return-rate calculations, automated data refresh, advanced customer segmentation, and Power BI Service publishing can be included to improve the overall analytical capabilities of the project.

Project Limitations

The dataset primarily contains product-level information, so actual sales revenue and sales performance cannot be calculated without appropriate transaction or sales data. Stock quantity should not be interpreted as the number of products sold, and return rates require suitable transaction-level information for accurate calculation.

Conclusion

The Fashion Product Data Visualization Dashboard provides an interactive way to explore and understand fashion product information. This project helped me improve my knowledge of data preparation, Power BI visualization, DAX, and dashboard development. It demonstrates how raw data can be transformed into an informative and user-friendly dashboard for analytical purposes.
